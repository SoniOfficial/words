# SONI WORDS V1.0

Android vocabulary-learning app (Tajik / Russian / English).

## Build
Requires JDK 17 and Gradle 8.13:
```bash
gradle assembleDebug
```
APK output:
`app/build/outputs/apk/debug/app-debug.apk`

## Package
`tj.soni.words`

## GitHub Actions
Push to `main` or run **Build SONI WORDS APK** manually from Actions.
